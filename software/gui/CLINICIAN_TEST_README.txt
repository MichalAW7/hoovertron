HooverTron Clinician Test Build
================================

How to run
----------
1. Extract the full zip folder.
2. Double-click HooverTron.exe.
3. Keep the HooverTron Patients folder next to HooverTron.exe.

Saving patient files
--------------------
The app saves patient CSV files automatically into the HooverTron Patients folder beside HooverTron.exe.

Enter a Patient ID (a study or clinic ID such as HT-0042), not the patient's name or date of birth. Files are named by Patient ID and visit date, e.g. HT-0042_2026-10-30-Visit.csv. Autosave starts once a Patient ID is entered.

Use Save to update the current patient CSV. Use Save As only if you want to export a copy somewhere else.

New patient workflow
--------------------
Use New Patient from the Results tab when moving to the next patient.

The app will ask whether to save the current patient's CSV before clearing the screen for the next patient.

Device note
-----------
At the end of a session, switch off HooverTron by double-pressing the power button on the battery pack.

Testing note
------------
This is a clinician testing build, not a final clinical release.
